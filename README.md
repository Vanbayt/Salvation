# Salvation

A unified, native music streaming client for Android. Salvation seamlessly aggregates audio streams from various major music platforms, bringing your entire library into one clean, focused application.

## Features

* **Multi-Platform Aggregation:** Access, search, and play music from multiple streaming services through a single, centralized interface.
* **Native Performance:** Built entirely in Kotlin, ensuring a smooth, responsive, and highly optimized Android experience.
* **Modern Design:** Features an intuitive and fluid UI built with modern Android development practices, fully supporting dynamic system-wide theming.
* **Secure Architecture:** The client communicates seamlessly with a private, custom-built backend infrastructure, ensuring fast delivery of streams and metadata without exposing any server-side logic or database structures.

## Technology Stack

* **Frontend:** Kotlin, Android SDK
* **Backend API (Private):** RESTful architecture powered by FastAPI and PostgreSQL.

## Overview

> **Note:** This repository contains the client-side application. Because Salvation relies on a private, closed-source backend for stream aggregation and data management, the code here is provided primarily for showcase, educational, and portfolio purposes. It is not intended for standalone local deployment without access to the primary API.
